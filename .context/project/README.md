## Contents

This directory contains stable, durable documentation committed to the repository.

### What Goes Here
- Architecture diagrams and system design
- Architecture Decision Records (ADRs)
- Operational runbooks
- Meeting notes
- Team guidelines

### What Does NOT Go Here
- Drafts and exploratory notes (use `.context/temp/`)
- Issue-specific workspaces (use `.context/issues/`)
- Generated reports (use `.context/reports/`)
- Sprint artifacts (use `.context/sprint/`)
